## 3. 设计基调

沿用 Element Plus light 主题与现有主色，不新增设计体系，只补一层项目变量（`src/styles/tokens.css`）：

| Token | 值 | 用途 |
|---|---|---|
| `--ea-color-primary` | `#F38181` | 主操作：继续观看、追番、进度条 |
| `--ea-bg` | `#F6F7FB` | 页面底色 |
| `--ea-surface` | `#FFFFFF` | 卡片、面板 |
| `--ea-border` | `#EDEFF5` | 分割线、卡片描边 |
| `--ea-text-1` | `#1F2329` | 标题 |
| `--ea-text-2` | `#6B7280` | 正文、元信息 |
| `--ea-text-3` | `#9CA3AF` | 辅助说明、占位 |
| `--ea-accent-update` | `#E6A23C` | 「更新」「NEW」 |
| `--ea-success` | `#67C23A` | 「已看完」 |
| `--ea-radius-sm/md/lg` | `8px` / `12px` / `16px` | 海报 / 卡片 / 弹窗 |
| `--ea-shadow-1/2` | `0 2px 8px rgba(31,35,41,.06)` / `0 8px 24px rgba(31,35,41,.12)` | 常态 / 悬浮 |
| `--ea-space-*` | `4/8/12/16/24/32` | 间距只取这六档 |
| `--ea-duration` | `150ms` / `250ms` | 悬浮 / 弹窗 |

规则：

- 封面统一 `aspect-ratio: 3/4`，圆角 `8px`，不加边框，不加投影（悬浮时才加 `--ea-shadow-2`）
- 海报上的文字只用底部渐变（`linear-gradient(0deg, rgba(0,0,0,.72), transparent 55%)`），不使用整块半透明黑底
- 不使用纯黑遮罩式 hover；悬浮只做「上浮 2px + 投影 + 显示操作」
- 主色只用于**当前可做的主动作**，一屏内主色块不超过 3 处
- 本轮只做浅色，不引入深色主题（跟随 Element Plus 默认）
- 图标统一 `@element-plus/icons-vue`，不引新图标库

## 4. 路由与信息架构

沿用 `AdminLayout`（顶部栏 + 左侧菜单 + keep-alive），不重构外层框架：

```
/admin/ani-home                   首页（追番台）
/admin/ani-opus/:id               详情页
/admin/ani-opus/:id?ep=<mediaId>  详情页 + 自动打开播放弹窗
/admin/ani-video/:id/:num/:time   旧链接 → 重定向到 /admin/ani-opus/:id?ek=<episodeKey>&t=<秒>
```

- 首页卡片点击 → 详情页（不再直接进播放）：先看信息、选集，再播放
- 首页「继续观看」卡片点击 → 详情页并自动打开弹窗 `?ep=<last_media_id>`（`lastMediaId` 出参为 `0` 表示没有可跳转的媒体，此时用 `last_episode_key` 反查，见主计划 §5.3 与 §6 序列化约定）
- 旧链接的 `num` 按 `episode_key` 规则归一后放进 `ek`，`time` 放进 `t`；详情页加载 `mediaList` 后反查 `mediaId` 并 `router.replace` 成 `?ep=&t=`，匹配不到就停在详情页提示「未找到该集」
- 详情页关闭弹窗：历史里有 `ep` 项就 `router.back()`，刷新直达的用 `router.replace` 去掉 `ep`，与浏览器后退键等价（不要一律 `replace`，否则后退键会退出详情页）
- keep-alive 改为按路由 `meta.keepAlive` 控制，详情页与播放层不复用缓存（避免播放器实例残留）

```

│ │ [▶ 继续观看]                   │ │            │ │            │  │
│ └───────────────────────────────┘ └────────────┘ └────────────┘  │
├──────────────────────────────────────────────────────────────────┤
│ 最近更新                                             查看全部 →    │

├──────────────────────────────────────────────────────────────────┤

│ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐         │
│ │    │ │    │ │    │ │    │ │    │ │    │ │    │ │    │         │
│ └────┘ └────┘ └────┘ └────┘ └────┘ └────┘ └────┘ └────┘         │
```

- 无截图资源（本轮不引 ffmpeg），「继续观看」大卡用封面做模糊背景 + 渐变，不做截帧
- 检索从固定右栏改为顶部按钮：点击展开搜索框，筛选进抽屉；`Esc` 或点击外部收起
- 首屏只加载前两屏内容，其余滚动到再取（封面 `loading="lazy"`）

### 5.2 区块规则

| 区块 | 数据 | 规则 |
|---|---|---|
| 继续观看 | `GET /anime/userOpus/continue`（按 `last_read_time` 倒序，排除「`read_status = 1` 且 `caughtUp`」，取 3 条；判定由后端完成，前端不再比较 `last_episode_key`） | 无记录整块隐藏；第一条为 16:9 大卡，其余为 3:4 小卡；`durationMs` 出参为 `0` 表示未知时长，此时不显示百分比 |
| 最近更新 | `/anime/update/latest?limit=12` | 横向滚动，末尾固定「查看全部」；单条显示「《番名》{displayName}」+ 相对时间，`create_time` 取文件 mtime；无集数条目不能拼成「第 N 集」 |
| 我的追番 | `POST /anime/opus/listByUser`，请求体带 `isFollow: 1`（返回 `completedCount` / `mediaCount` / `lastEpisodeKey` / `lastMediaId` / `hasUpdate` / `positionMs` / `durationMs` / `isCompleted` / `readStatus`） | 只含已追番的作品（不追番但有进度的不出现）；默认「全部」，排序默认「最近观看」，空值沉底；无集数文件的作品照常显示，元信息退化为放送时间 |

### 5.3 卡片

| 状态 | 表现 |
|---|---|
| 未看 | 无进度条，右上角无角标 |
| 在看 | 封面底部 3px 主色进度条 + 悬浮显示「{displayName} · 剩余 mm:ss」 |
| 已看完 | 右上角 ✓ 绿色角标（取接口 `isCompleted`，不要用 `readStatus` 自己推）；进度条另按 `completedCount / mediaCount` 画——手动标「已看完」时角标出 ✓、条却可能不满格，不要为了对齐去改条的数据源 |
| 有更新 | 右上角「NEW」橙色角标，优先级高于「已看完」 |
| 无资源 | 封面 `filter: saturate(.2) opacity(.6)`，角标「等待资源」，点击进详情但不播放 |
| 无集数文件 | 进度与角标照常，集数文案改用 `display_name`（如「剧场版」、文件名去扩展名），不显示「第 null 集」 |
| 悬浮 | 上浮 2px + `--ea-shadow-2` + 居中播放按钮（仅桌面） |

卡片信息区固定两行：番名（1 行省略）+ 元信息（`已看 5/12 · 每周三` 或 `2026/04`），不再出现第三个按钮。所有「第 N 集」文案统一取接口返回的 `display_name`，不在前端拼集数。

### 5.4 交互

| 操作 | 行为 |
|---|---|
| 点击卡片 | 进详情页 |
| 点击播放按钮 | 进详情页并打开弹窗（`?ep=`） |
| 追番 | 只在详情页与卡片「更多」菜单里，卡片 hover 不再直接暴露 |
| 投喂 | 收进卡片「更多」菜单（`⋯`），弹窗沿用现有用户选择交互 |
| 筛选/搜索 | 只改 URL query，刷新可复现；不触发全页 loading 遮罩，内容区局部骨架 |
| 空态 | 无追番：「还没有追番，去搜索一部吧」+ 搜索按钮；无更新：整块隐藏 |

```
┌──────────────────────────────────────────────────────────────────┐

│ ┌──────┐ 中文名（28px）                                            │

│ └──────┘ [日常][治愈][音乐]                                        │
│          [▶ 继续观看 第 5 集 · 12:34] [追番] [标记已看完] [⋯]       │
├──────────────────────────────────────────────────────────────────┤
│ 简介                                            展开               │
├──────────────────────────────────────────────────────────────────┤
│ 正片 12    [1][2][3][4][5][6][7][8]…                              │
│ SP / OVA 2 [SP1][SP2]                                             │
├──────────────────────────────────────────────────────────────────┤
```

- Hero 高度 `min(420px, 45vh)`；无背景图时退化为纯色 + 封面
- 主操作最多 2 个主色按钮：有进度显示「继续观看 {display_name}」，无进度显示「开始观看」；`lastMediaId` 为 `0` 但 `lastEpisodeKey` 非空时按其反查，两者都空则指向第一集

- 移动端：hero 变上下堆叠（封面 96px 宽），主操作占满一行，剧集 4 列

### 6.2 剧集网格

| 项 | 规则 |
|---|---|
| 数据源 | 只取 `ani_media` 中 `is_deleted = 0 AND is_primary = 1` 的行；同集多文件只出现一个按钮 |
| 分组 | `isExtra = 0` → 正片；`isExtra = 1` → SP / OVA / 剧场版 / 其他（`display_name` 区分）。**不要用 `episode_no` 是否为空判断**——出参时 `null` 会被序列化成 `0`（主计划 §6 序列化约定） |
| 组内顺序 | 直接用接口返回的顺序（服务端已按 `sort_no IS NULL, sort_no, id` 排好）；**前端不要再按 `sortNo` 重排**：`null` 出参会变成 `0`，重排会把无集数的剧场版/PV 排到最前面 |
| 单元 | 方形按钮：正片显示 `episodeNo`（`5`、`12.5`），SP 显示 `displayName`（`SP1`），无集数显示 `displayName`（文件名去扩展名后截断）。不要从 `displayName` 里反解数字 |
| 未看 | 白底描边 |
| 在看 | 主色描边 + 底部 2px 进度条（按该集 `positionMs / durationMs`，`durationMs <= 0` 时（未知时长）不显示进度条） |
| 已看完 | 浅灰底 + ✓ |
| 最新一集 | 右上角小圆点，以 `media_latest_key` 为准（正片组里 `sort_no` 最大的一个，不是字符串最大；定义见主计划 §5.1，SP 不会抢这个位置） |
| 悬浮 | 显示「{display_name} · 剩余 xx:xx」tooltip |
| 无资源 | 整个剧集区显示「尚未扫描到资源」，不渲染空按钮占位 |

## 7. 播放层（弹窗）

### 7.1 结构

```
┌──────────────────────────────────────────────────────────────────┐
│ 《作品名》 第 5 集                                        ✕        │  ← 鼠标静止 3s 后隐藏
│ ┌──────────────────────────────────────────────────────────────┐ │
│ │                        video（16:9）                         │ │
│ │                    [▶]  00:12 / 24:00   [选集][全屏]          │ │
│ └──────────────────────────────────────────────────────────────┘ │
│ 选集  [1][2][3][4][5][6][7][8] …                                  │  ← 可折叠，默认展开
└──────────────────────────────────────────────────────────────────┘
```

- 尺寸 `min(1200px, 92vw)`，16:9；弹窗背景 `#0B0B0F`，圆角 `--ea-radius-lg`
- 遮罩 `rgba(12,12,16,.72)`，点击不关闭（防误触）
- 顶部栏与选集条随控制条一起显隐，200ms 淡入淡出
- 切集不销毁实例：`player.src` 切换，选集条高亮跟随；切换前先 `flush` 当前集进度，再把新集位置置 0，并 `router.replace({query:{ep: 新mediaId}})` 同步 URL（主计划 §5.3）
- 移动端：`100vw × 100vh` 全屏，横屏自动全屏；选集条改为底部抽屉
- 关闭动画 200ms 后卸载；关闭前 `flush` 进度，并同时挂 `pagehide` → `sendBeacon`，避免直接关标签页丢进度
- 媒体流靠 cookie 鉴权（`<video>` 发不出自定义 header），不上 header token、不拼 token 到 URL；登录本来就会写 `Authorization` cookie，但默认没配 `Path`（作用域只有 `/api/system`），主计划 P1 在 `sa-token.cookie` 里补 `path: /` + `HttpOnly` + `SameSite=Lax`（§5.6）。`<video src>` = `API_BASE` + `/anime/media/{mediaId}/stream`——目前并没有这个常量（`axios-util.ts:19/69` 把 `/api/${url}` 写死），主计划 P1 会把它提成导出的 `API_BASE`（默认 `/api`，可用 `VITE_API_BASE` 覆盖），播放层直接引用，**不要再写一份 `/api`**。dev / docker 是 `/api`，release 是 `/` 靠前置代理，漏了前缀会直接 404

### 7.2 快捷键

| 键 | 行为 |
|---|---|
| `Space` / `K` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5s |
| `↑` / `↓` | 音量 ±10% |
| `M` | 静音 |
| `F` | 全屏切换 |
| `Esc` | 全屏中先退全屏；否则关闭弹窗 |
| `[` / `]` | 上一集 / 下一集 |

快捷键只在弹窗打开且焦点不在输入框时生效。

### 7.3 状态

| 场景 | 表现 |
|---|---|
| 打开中 | 播放器区域骨架 + 「正在加载…」，不闪白 |
| 续播 | 恢复成功后 toast：「已从 12:34 继续播放」，5s 自动消失；`position / duration ≥ 0.95` 视为看完，从头播且不提示 |
| 加载失败 | 弹窗内错误卡片：原因 + 「重试」+「重新扫描」（有权限）；HTTP 401 单独识别成「登录已失效，请重新登录」，不要和「编码不支持」混在一起（流接口自己写状态码，见主计划 §5.6） |
| 编码不支持 | 错误卡片提示容器格式（如 HEVC/AV1），给出建议 |
| 自动下一集 | 播完非最后一集：3s 倒计时条 + 「立即播放」，可取消；倒计时期间关闭弹窗或切集即取消；最后一集：提示「已看完本番」 |

## 9. 样式规范

- 所有新组件 `<style scoped>`，禁止再用 `<style src>` 引入全局 CSS
- 颜色、间距、圆角、动效一律取 `--ea-*`，不写死十六进制
- 类名前缀：页面级 `ea-home__` / `ea-detail__`，组件内用 BEM 短名
- 状态类统一：`.is-active` / `.is-done` / `.is-new` / `.is-disabled`
- 动画尊重 `prefers-reduced-motion: reduce`，关闭上浮与淡入
